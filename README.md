# WDIO-ASSESSMENT
WDIO assessment.

To execute:

Download the project, using the terminal, navigate to root folder
run "NPM install" to get all the dependencies
Connect an mobile device and update the Capabilities file under  config folder with device caps,
When you ready, execute "npm run run-all" to execute Both Android and API tests,
For Android, execute "NPM run wdio:Andriod"
For IOS, execute "NPM run wdio:IOS"
for API, Execute "NPM run wdio:api"
